# 0004：安装凭据与后台管理壳

## 状态

已接受，2026-08-04。

## 背景

Simplus 是可信局域网中的单管理员工具。原首次运行流程要求 root 生成短时 Bootstrap URL，并把管理员创建、存储、HTTPS、硬件复核和线路访问模式串成一个阻塞向导。它增加了安装操作和页面复杂度，也把日后可独立维护的配置错误地固化为首次启动前置条件。

## 决策

- Debian 安装器在全新实例上自动创建唯一管理员 `simplus_admin`，使用密码学安全随机密码，只在安装 CLI 显示一次；数据库仅保存 Argon2id 哈希。
- 升级已有实例不得覆盖管理员或再次显示凭据。root CLI 提供显式密码重置作为恢复入口。
- 未完成基础初始化时，已配置管理员可以正常登录，但业务 API 继续由 installation state 阻断。
- 首次登录只完成必要的本机存储确认，然后原子进入 ready。
- HTTPS 移到系统设置；模组发现与配置移到模组配置；线路和访问模式移到线路配置。它们不再阻塞首次登录。
- Web 使用常见后台管理壳：左侧导航，右侧路由内容。V1 导航至少包含概览、模组配置、线路配置、短信、语音通话、Mihomo 配置和系统设置。

## 边界

- 自动生成不等于默认密码；每个新实例的密码独立且高熵。
- 凭据输出可能进入终端记录，安装说明必须要求首次登录后修改密码；不得写入文件、日志或环境变量。
- LAN HTTP 仍仅用于可信私网。HTTPS 在设置页显式启用，不自动签发或绑定公网地址。
- 本决策不改变 V1 真实硬件只读策略，也不授权 RF、短信、通话、eUICC 或数据写操作。
