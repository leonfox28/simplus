# Local reference material

This directory is reserved for hardware manuals, schematics, PCB documents, firmware notes, and other vendor reference material used during Simplus development.

Except for this file, `ref/` is intentionally excluded from Git because the files may be large, version-specific, or subject to vendor redistribution terms. Keep local copies here and record public source URLs, document versions, evidence, and conclusions in the tracked project documentation.

Do not place credentials, SIM identities, customer data, raw diagnostic captures, firmware dumps, or replayable AKA/APDU material in this directory.
