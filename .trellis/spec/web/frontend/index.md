# `@simplus/web` Frontend Guidelines

> Executable conventions for the React management application in `web/`.

## Scope

The frontend is a React 19 single-page application built by Vite. React Router
8 runs in declarative mode, pages compose Ant Design 6 directly, and TanStack
Query owns server snapshots. The HTTP client, TypeScript models, Zod validators,
query keys/options, and mutation options are generated by Hey API from
`api/openapi.yaml`.

`docs/decisions/0022-vite-react-query-web-runtime.md` supersedes the Umi and
Ant Design Pro parts of ADR 0009. The visual language remains Ant Design, but
`@umijs/*`, `@ant-design/pro-*`, ProLayout, and framework runtime hooks are not
part of the current stack.

## Pre-Development Checklist

- Read `docs/architecture.md` and ADR 0022 before changing routing, state, or
  browser/API communication.
- Start public contract changes in `api/openapi.yaml`; never patch generated
  files in `web/src/api/generated/`.
- Read the focused guide below and the nearest page/API test.
- Keep HTTP authoritative. SSE is a bounded invalidation/attention signal, not
  a second data model.
- Preserve the hardware and HIL safety boundary: browser code uses only typed
  business APIs and never exposes arbitrary commands or device paths.

## Architecture at a Glance

```text
web/src/main.tsx
  -> AppProviders (Ant Design + QueryClient + BrowserRouter)
  -> BootstrapGate (setup/session routing)
  -> AppRouter (explicit lazy routes)
  -> AppShell (desktop Sider / mobile Drawer + Outlet + RealtimeBridge)
  -> pages/*.tsx
       -> generated TanStack Query options/mutations
       -> generated SDK -> configured Fetch runtime -> /api/v1 HTTP

/api/v1/events (SSE)
  -> RealtimeBridge
  -> validate RealtimeEvent
  -> invalidate matching active queries
  -> those queries refetch authoritative HTTP snapshots
```

## Core Decisions

- Import routing APIs from `react-router`, UI primitives from `antd`, and icons
  from `@ant-design/icons`; do not introduce Umi or Pro Components.
- Define routes explicitly in `web/src/app/AppRouter.tsx` and navigation in
  `web/src/app/navigation.tsx`. Authentication/setup redirects belong in
  `BootstrapGate`, not in individual business pages.
- Use generated `*Options`, `*InfiniteOptions`, and `*Mutation` helpers. Build
  query invalidation from generated keys/tags rather than handwritten endpoint
  strings.
- Keep persistent state in the backend. Query cache contains replaceable HTTP
  snapshots; form drafts, open dialogs, and row operation IDs remain local.
- Use `ResponsiveDataView` for record-heavy views: Ant Design `Table` on wide
  screens and full record cards on compact screens.
- Validate both requests and successful responses at the generated SDK
  boundary. Keep topology cross-reference validation in
  `web/src/api/hardwareSchema.ts`.
- SSE carries only bounded topics and optional attention codes. It never carries
  message bodies, phone numbers, hardware identities, or the authoritative
  resource state.

## Required Checks

```bash
corepack pnpm --dir web typecheck
corepack pnpm --dir web test
corepack pnpm --dir web build
corepack pnpm --dir web e2e
make verify-generated
make security
```

Use the focused commands first, then the repository-level gate for shared API,
CI, or dependency changes. No real hardware, SMS, call, RF, or modem-persistent
action is part of these browser checks.
