# 修复 Mihomo 订阅更新管理服务错误

## Goal

让管理员点击 Mihomo 订阅“更新”后得到正确、可操作且不泄露敏感信息的结果；若当前订阅服务可通过受支持的客户端请求方式读取，则完成下载、转换、校验和原子发布，若上游拒绝请求，则明确显示订阅源拒绝而不是笼统的“管理服务”故障。

## Background

- 用户提供的页面截图显示，订阅更新 mutation 失败，页面只显示“管理服务暂时无法完成该操作”，订阅行标记为“更新失败”。
- 生产容器均健康，Mihomo 当前仍在运行，已安装 core 为 `v1.19.29`；故障不等同于进程或 netd 整体不可用。
- 经脱敏分类的应用日志显示，最近两次失败均为订阅上游返回 HTTP 403。未读取或记录订阅正文、节点、完整 URL 或访问令牌。
- 当前下载请求在 `internal/application/mihomo/subscriptions.go:299` 固定发送 `User-Agent: Simplus`。经用户明确授权后，对同一个已配置公网 HTTPS 目标进行脱敏只读探测：`Simplus` 返回 403，而 `mihomo`、`clash.meta` 和 `clash` 均返回 200。探测只输出匿名请求标签和状态码，未保存响应正文。
- 当前后端把上游刷新失败映射为稳定代码 `MIHOMO_SUBSCRIPTION_REFRESH_FAILED`，但 Web 未为该代码提供专用文案，因此回落到通用 HTTP 错误提示。
- `internal/api/httpapi/server.go:1488` 通过检查错误字符串来识别刷新失败；网络错误还可能把含访问令牌的完整请求 URL 包进 `Error()` 后写入普通日志。
- 应用服务的完整刷新成功/失败路径以及 HTTP 错误映射目前缺少针对性回归测试。

## Requirements

- R1：保留订阅下载的公网 HTTPS、DNS 重绑定、重定向次数、响应大小和超时防护，不因兼容性修复放宽 SSRF 或资源边界。
- R2：下载、解析和工件构建阶段的预期失败必须返回类型化、可由 HTTP 层可靠识别且字符串表示不含底层敏感原因的刷新错误；数据库失败继续作为独立持久化错误处理。
- R3：订阅下载请求使用现场证据已证明兼容的最小稳定标识 `User-Agent: mihomo`，并由合成 HTTP fixture 覆盖；不得针对单个私有域名写例外。
- R4：刷新失败不得破坏最后一次通过校验的不可变工件或当前运行配置；失败状态和有界错误码仍需持久化并可在列表中观察。
- R5：现有公开 HTTP 502 与 `MIHOMO_SUBSCRIPTION_REFRESH_FAILED` 契约保持不变；Web 应把该错误显示为可操作、非误导的中文提示，而不是宣称管理服务不可用。
- R6：实现、检查和收尾均由当前主会话完成，不使用子代理。

## Acceptance Criteria

- [x] AC1：合成测试证明刷新请求发送精确的 `User-Agent: mihomo`；上游返回有效订阅时节点被替换、刷新状态变为 `success`，并调用工件构建边界。
- [x] AC2：合成测试证明上游 403/非 200、网络失败或超时返回类型化刷新错误，`Error()` 不含 URL、令牌、响应正文或底层私密标记，并持久化 `SUBSCRIPTION_FETCH_FAILED`。
- [x] AC3：解析及配置生成/校验失败同样返回类型化刷新错误并保留对应的持久状态码；HTTP 层通过类型而非字符串匹配映射到既有 502 契约，数据库失败仍映射为 500 持久化错误。
- [x] AC4：Web 对 `MIHOMO_SUBSCRIPTION_REFRESH_FAILED` 显示订阅源访问/有效性检查提示，mutation 失败后清理行级 busy 状态并保留现有数据。
- [x] AC5：现有 SSRF、原子工件、运行态和隐私边界测试继续通过；不执行真实 SMS、通话、RF、modem 写入或 HIL 操作。

## Key Decisions

- 使用 `mihomo` 而不是伪造某个带版本的第三方客户端标识；它是满足现场 200 响应的最小值，也不会把私有部署信息放进请求。
- 保留现有 OpenAPI 状态和错误码，不引入生成文件变更；精细阶段原因继续通过订阅记录的有界 `lastErrorCode` 表达。
- 新的刷新错误只携带稳定阶段代码，不包装或暴露原始 HTTP/URL 错误；HTTP 日志记录该稳定代码。
- 所有自动化验证使用合成 URL、HTTP response 和节点；不把真实订阅、日志或数据库复制进任务或测试。
- 本任务按用户要求采用当前会话内联实现和检查，不生成或派发子代理上下文。

## Out of Scope

- 修改或续费第三方订阅账户、令牌、套餐、IP 白名单或 WAF 规则。
- 针对某个私有订阅域名加入硬编码绕过。
- 改变 Mihomo core 版本、真实运行配置、线路出口或 Host VoWiFi 生命周期。
- 在任务材料、测试、提交或最终说明中保存私有 URL、节点、原始日志或响应正文。
- 将本次只读探测扩展为真实生产刷新或修改第三方订阅账户、令牌、套餐、IP 白名单和 WAF 规则。
